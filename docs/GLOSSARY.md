## MTG Grundbegriffe

| Begriff | Erklärung |
|---------|-----------|
| **Magic: The Gathering (MTG)** | Sammelkartenspiel von Wizards of the Coast, seit 1993 |
| **Arena** | Digitale Version von MTG (MTG Arena), kostenlos spielbar |
| **Paper** | Physische Karten, die man sammeln und handeln kann |
| **Collection** | Die Gesamtheit aller Karten, die ein Spieler besitzt |
| **Deck** | Spielbares Kartenstapel (meist 60 oder 100 Karten) |
| **Karte** | Einzelne Spielkarte mit Name, Kosten, Typ und Fähigkeiten |
| **Bibliothek** | Der Nachziehstapel während eines Spiels |
| **Hand** | Die Karten, die ein Spieler auf der Hand hält |
| **Friedhof** | Ablagestapel für benutzte/zerstörte Karten |

## Karten-Eigenschaften

### Farben (WUBRG)

| Symbol | Farbe | Englisch | Spielstil |
|--------|-------|----------|-----------|
| **W** | Weiß | White | Ordnung, Schutz, Kreaturen-Verstärkung |
| **U** | Blau | Blue | Kontrolle, Kartenziehen, Counter |
| **B** | Schwarz | Black | Tod, Opferung, Ressourcen-Tausch |
| **R** | Rot | Red | Aggression, Direktschaden, Tempo |
| **G** | Grün | Green | Kreaturen, Mana-Beschleunigung, Natur |
| **C** | Farblos | Colorless | Artefakte, Eldrazi, generische Kosten |

> **Hinweis**: "WUBRG" wird als "wuberg" ausgesprochen und ist die Standard-Reihenfolge der Farben.

### Mana & Kosten

| Begriff | Erklärung |
|---------|-----------|
| **Mana** | Ressource zum Spielen von Karten |
| **Manakosten** | Kosten in der oberen rechten Ecke einer Karte |
| **CMC** | Converted Mana Cost - Gesamtkosten als Zahl |
| **Manabasis** | Die Länder in einem Deck zur Mana-Produktion |
| **Mana-Kurve** | Verteilung der CMC-Werte im Deck (Diagramm) |
| **Splash** | Eine dritte Farbe mit wenigen Karten hinzufügen |

### Kartentypen

| Typ | Beschreibung |
|-----|--------------|
| **Creature** | Kreatur - kann angreifen und blocken |
| **Instant** | Spontanzauber - jederzeit spielbar |
| **Sorcery** | Hexerei - nur in eigener Hauptphase |
| **Enchantment** | Verzauberung - dauerhafter Effekt |
| **Artifact** | Artefakt - farbloses Dauerhaftes |
| **Planeswalker** | Mächtiger Verbündeter mit Loyalitätsfähigkeiten |
| **Land** | Länder - produzieren Mana |
| **Battle** | Schlacht - neue Kartenart (ab 2023) |

### Seltenheit (Rarity)

| Symbol | Seltenheit | Beschreibung |
|--------|------------|--------------|
| **C** | Common | Häufig, schwarzes Set-Symbol |
| **U** | Uncommon | Ungewöhnlich, silbernes Symbol |
| **R** | Rare | Selten, goldenes Symbol |
| **M** | Mythic Rare | Mythisch selten, orange Symbol |

### Weitere Eigenschaften

| Begriff | Erklärung |
|---------|-----------|
| **Set / Edition** | Kartensammlung mit Thema (z.B. "Dominaria United") |
| **Set-Symbol** | Icon das anzeigt aus welchem Set eine Karte stammt |
| **Oracle Text** | Offizieller, aktueller Regeltext einer Karte |
| **Flavor Text** | Geschichte/Atmosphäre-Text (kursiv, keine Regeln) |
| **Kreaturentyp** | Subtyp wie "Elf", "Goblin", "Dragon", "Zombie" |
| **Keywords** | Schlüsselwörter wie "Flying", "Trample", "Deathtouch" |

## Formate & Regeln

### Arena-Formate

| Format | Deck-Größe | Beschreibung |
|--------|------------|--------------|
| **Standard** | 60 | Letzte 2-3 Jahre Sets, rotiert jährlich |
| **Historic** | 60 | Alle Arena-Karten + Anthologies |
| **Explorer** | 60 | Pioneer-Karten die auf Arena verfügbar sind |
| **Brawl** | 60 | Commander-Variante mit 1 Commander |
| **Alchemy** | 60 | Standard mit digitalen Rebalances |
| **Timeless** | 60 | Alles erlaubt, keine Banlist |

### Paper-Formate

| Format | Deck-Größe | Beschreibung |
|--------|------------|--------------|
| **Commander (EDH)** | 100 | 1 Commander, Singleton (nur 1 Kopie pro Karte) |
| **Modern** | 60 | Karten ab 8th Edition (2003) |
| **Legacy** | 60 | Alle Karten, strenge Banlist |
| **Vintage** | 60 | Alle Karten, Restricted statt Banned |
| **Pioneer** | 60 | Karten ab Return to Ravnica (2012) |
| **Pauper** | 60 | Nur Commons erlaubt |

### Regelbegriffe

| Begriff | Erklärung |
|---------|-----------|
| **Legal** | Karte ist im Format erlaubt |
| **Banned** | Karte ist verboten (nicht spielbar) |
| **Restricted** | Nur 1 Kopie erlaubt (nur Vintage) |
| **Suspended** | Temporär verboten (nur Arena) |
| **Rotation** | Jährliches Entfernen alter Sets aus Standard |
| **Sideboard** | 15 Karten zum Austauschen zwischen Spielen |
| **Singleton** | Nur 1 Kopie jeder Karte erlaubt (außer Basic Lands) |

## Deck-Building

### Archetypen

| Archetype | Beschreibung | Typische Farben |
|-----------|--------------|-----------------|
| **Aggro** | Schnell, viele kleine Kreaturen, früher Sieg | R, W, RW |
| **Control** | Langsam, viel Entfernung, später Sieg | U, UB, UW |
| **Midrange** | Ausgewogen, effiziente Kreaturen | GB, GR, any |
| **Combo** | Gewinnt durch Kartenkombination | varies |
| **Ramp** | Schnelle Mana-Beschleunigung | G, GU |
| **Tribal** | Fokus auf einen Kreaturentyp | varies |
| **Tokens** | Erzeugt viele kleine Kreatur-Token | W, GW |
| **Reanimator** | Holt große Kreaturen aus dem Friedhof | B, UB |
| **Mill** | Gewinnt durch leere Bibliothek des Gegners | U, UB |
| **Burn** | Direktschaden auf Gegner | R, RW |

### Deck-Begriffe

| Begriff | Erklärung |
|---------|-----------|
| **Meta / Metagame** | Die aktuell beliebtesten/stärksten Decks |
| **Tier** | Stärke-Ranking (Tier 1 = Top-Decks) |
| **Netdeck** | Deck aus dem Internet kopiert |
| **Brew** | Selbst erstelltes, experimentelles Deck |
| **Staple** | Karte die in vielen Decks gespielt wird |
| **Wincon** | Win Condition - wie das Deck gewinnt |
| **Curve out** | Jede Runde perfekt Mana nutzen |
| **Flood** | Zu viele Länder ziehen |
| **Screw** | Zu wenige Länder ziehen |
| **Mulligan** | Starthand zurückmischen und neu ziehen |

## Arena-spezifisch

| Begriff | Erklärung |
|---------|-----------|
| **Wildcard (WC)** | Joker-Karte zum Einlösen beliebiger Karten |
| **Common WC** | Wildcard für Common-Karten |
| **Uncommon WC** | Wildcard für Uncommon-Karten |
| **Rare WC** | Wildcard für Rare-Karten |
| **Mythic WC** | Wildcard für Mythic-Karten |
| **Gems** | Premium-Währung (für Drafts, Cosmetics) |
| **Gold** | Kostenlose Währung (für Events, Packs) |
| **Vault** | Versteckter Progress für Wildcards bei Duplikaten |
| **ICR** | Individual Card Reward - zufällige Kartenbelohnung |
| **Draft** | Limited-Format: Karten aus Boostern wählen |
| **Sealed** | Limited-Format: Deck aus 6 Boostern bauen |

## Paper-spezifisch

| Begriff | Erklärung |
|---------|-----------|
| **Original** | Echte, physische MTG-Karte von WotC |
| **Proxy** | Ersatzkarte (Ausdruck oder Placeholder) |

| **Near Mint (NM)** | Zustand: Wie neu, keine Gebrauchsspuren |
| **Excellent (EX)** | Zustand: Minimale Gebrauchsspuren |
| **Good (GD)** | Zustand: Sichtbare Gebrauchsspuren |
| **Played (PL)** | Zustand: Deutliche Gebrauchsspuren |
| **Sleeve** | Schutzhülle für Karten |
| **Double-Sleeve** | Zwei Hüllen für maximalen Schutz |
| **Cardmarket** | Europäischer Marktplatz für Karten |
| **TCGPlayer** | US-amerikanischer Kartenmarkt |
| **LGS** | Local Game Store - lokaler Spieleladen |
| **FNM** | Friday Night Magic - wöchentliches Event |

## Technische Begriffe

### Anwendung

| Begriff | Erklärung |
|---------|-----------|
| **OCR** | Optical Character Recognition - Texterkennung aus Bildern |
| **Scryfall** | API/Datenbank mit allen MTG-Karten |
| **Tesseract** | Open-Source OCR-Engine |
| **AI Correction** | KI-gestützte Korrektur von OCR-Fehlern |
| **Grid Detection** | Automatisches Erkennen des 12x3 Kartenrasters |
| **Empty Slot Detection** | Erkennung leerer Kartenpositionen |
| **Edge Detection** | Kantenerkennung zur Unterscheidung leer/gefüllt |
| **Confidence Score** | Vertrauenswert der OCR-Erkennung (0-100%) |

### Datenmodell

| Begriff | Erklärung |
|---------|-----------|
| **ArenaCollection** | Sammlung virtueller Arena-Karten eines Users |
| **PaperCollection** | Sammlung physischer Karten eines Users |
| **DeckCard** | Verknüpfung Deck ↔ Karte mit Anzahl |
| **CoverImage** | Titelbild eines Decks |
| **Archetype** | Kategorisierung des Deck-Spielstils |
| **Domain** | Bereich: "arena" oder "paper" |
| **Scryfall ID** | Eindeutige Karten-ID von Scryfall |
